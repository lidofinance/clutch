## Standing gates

- **Traceability:** each permission traces to a specification clause, ADR, test and deployed artifact.
- **One-command verification:** one command verifies each permission change.
- **Six hours:** fork drills prove that each emergency action starts within six hours.
- Financial figures enter documents only if an attested computation produced them.
- Only EM or the Treasury Management Committee accepts ADRs.
